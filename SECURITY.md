# Segurança e comunicação responsável

A CAOS é um diretório público de links. A segurança do projeto depende também da segurança dos visitantes e das fontes catalogadas.

## Reportar uma vulnerabilidade

Não publique detalhes exploráveis em Issues ou Pull Requests. Envie um relato privado ao mantenedor pelo canal de contato disponibilizado no perfil do GitHub do projeto. Inclua:
- página, arquivo ou componente afetado;
- impacto observado e condições para reproduzir, sem expor dados de terceiros;
- uma forma segura de contato para esclarecimentos.

Não inclua senhas, tokens, chaves de API, dados pessoais ou conteúdo privado no relato.

## Escopo

São relevantes, entre outros:
- execução de scripts ou conteúdo não confiável no portal;
- links que levem a phishing, malware ou downloads enganosos;
- exposição acidental de credenciais ou dados pessoais;
- comprometimento do fluxo de publicação ou da conta mantenedora.

A inclusão de um link no catálogo não representa verificação permanente nem endosso da fonte.
