# Como contribuir com a CAOS

Obrigado por ajudar a mapear o conhecimento público do mundo.

## Sugerir uma fonte

Abra uma issue no GitHub ou envie um pull request adicionando um registro a `data/sources.json`.

Cada registro deve conter:

- `id`: número inteiro único.
- `title`: nome oficial da fonte.
- `category`: `natural`, `formal`, `social`, `health`, `engineering` ou `cross`.
- `subcategory`: campo ou finalidade específica.
- `description`: descrição factual e concisa em inglês.
- `description_pt`: descrição factual e concisa em português brasileiro.
- `url`: endereço canônico HTTPS sempre que possível.
- `type`: por exemplo, base de dados, repositório, portal de dados, entidade de normalização, biblioteca ou portal institucional.
- `access`: informe corretamente se o acesso é gratuito, misto, exige cadastro ou é restrito.
- `tags`: termos úteis para busca.

## Princípios de curadoria

1. Priorize fontes primárias, universidades, instituições públicas de pesquisa, repositórios acadêmicos reconhecidos e infraestruturas de dados estabelecidas.
2. Verifique se o destino está acessível e é relevante antes de enviar.
3. Explique o que o visitante encontrará; evite linguagem promocional.
4. Não classifique uma fonte como acesso aberto apenas porque sua página inicial é gratuita.
5. Diferencie publicações revisadas por pares de preprints e materiais não revisados.
6. Inclua ressalvas de licença e reutilização quando conhecidas.
7. Evite duplicatas, fazendas de links, malware, downloads enganosos e fontes que facilitem atividades ilegais ou violações de privacidade.
8. Não envie dados pessoais, credenciais vazadas, registros privados ou materiais obtidos sem autorização.
9. Não use o diretório para visar, perfilar ou vigiar indivíduos privados.
10. Mantenha descrições neutras e baseadas em evidências.

## Classificação

Use a taxonomia de cinco áreas descrita no README. Se uma fonte abranger várias disciplinas, escolha a categoria principal mais útil ou use `cross` para infraestruturas genuinamente multidisciplinares.

## Pull requests

Mantenha as alterações focadas. Explique por que a fonte é valiosa e inclua limitações de acesso ou licença. Toda contribuição está sujeita à revisão humana; a inclusão não é automática.

A CAOS é um índice, não um endosso. Cada pessoa deve avaliar as fontes em seu contexto.
