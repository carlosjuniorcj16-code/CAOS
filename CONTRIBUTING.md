# Contributing to CAOS

Thank you for helping map the world's public knowledge.

## Suggest a resource

Open a GitHub issue or submit a pull request adding an entry to `data/sources.json`.

Each entry should contain:

- `id`: unique integer.
- `title`: official resource name.
- `category`: `natural`, `formal`, `social`, `health`, `engineering` or `cross`.
- `subcategory`: specific field or purpose.
- `description`: concise, factual description.
- `url`: canonical HTTPS URL whenever possible.
- `type`: e.g. database, repository, data portal, standards body, library or institutional portal.
- `access`: accurately describe free, mixed, account-required or restricted access.
- `tags`: useful search terms.

## Curation principles

1. Prefer primary sources, universities, public research institutions, recognized scholarly repositories and established data infrastructures.
2. Verify that the destination is relevant and currently reachable before submitting.
3. Explain what a visitor can find there; avoid promotional language.
4. Do not label a resource open access merely because its landing page is free.
5. Distinguish peer-reviewed publications from preprints and unreviewed material.
6. Include licensing or reuse caveats when known.
7. Avoid duplicate entries, link farms, malware, deceptive downloads and sources that facilitate illegal activity or privacy violations.
8. Do not submit personal data, leaked credentials, private records or material obtained through unauthorized access.
9. Do not use the directory to target, profile or surveil private individuals.
10. Keep descriptions neutral and evidence-based.

## Classification

Use the five-domain taxonomy in the README. If a resource spans several disciplines, use the most useful primary category or `cross` for genuinely multidisciplinary infrastructure.

## Pull requests

Keep changes focused. Explain why the source is valuable and include any relevant access or licensing limitations. Human review is expected; acceptance is not automatic.

CAOS is an index, not an endorsement. Users should evaluate sources in context.
